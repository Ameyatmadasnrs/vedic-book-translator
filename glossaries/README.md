# Glossaries & Orthographic Rules

This directory contains authoritative linguistic and theological datasets used by the **Translation Engine** and **Quality Control System**.

## Contents

1. **`gaudiya_vaishnava_terms.json`**:
   - Curated dictionary of fundamental Gaudiya Vaishnava philosophical terms, concepts, and theological definitions.
   - Includes Sanskrit (Devanagari & IAST), authorized Russian BBT translation, alternative academic forms, definition, grammatical class, and explicitly forbidden/rejected translations.

2. **`sanskrit_diacritics_map.json`**:
   - Full mapping table of Sanskrit phonemes: Devanagari script ↔ IAST Unicode ↔ Harvard-Kyoto ↔ Cyrillic academic transliteration ↔ Cyrillic BBT phonetic standard.

3. **`bbt_russian_orthography_rules.json`**:
   - Formal rules for Russian transliteration of Sanskrit proper names (avatars, sages, deities, places), Sanskrit compound word handling, and Russian case declension patterns for loanwords.
